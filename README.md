# AniShelf

Anime library manager with wireless SMB2/3 transfer to Android.

Built with Tauri, Rust, and vanilla web technologies.

## Features

- Browse and manage your anime collection locally
- Wireless file transfer to Android devices via SMB2/3 protocol
- Fast and lightweight desktop application

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- [Rust](https://www.rust-lang.org/) (latest stable)

## Getting Started

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```

## Tech Stack

- **Frontend:** Vanilla HTML/CSS/JS
- **Backend:** Rust (Tauri)
- **Transfer Protocol:** SMB2/3
